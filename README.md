# MCS-Inventory-Server

This is a fully fledged inventory management system for a company called Marine Custom Solutions in Daytona Beach, Florida. This is simply just the project code for the program, the code is not connected to the companys SQL database. The program is made using the python Django framework.

To run the program, the pip dependencies must be installed, as well as some brew dependencies.

This code may not be downloaded or used by anyone except the company and the creator of the program.
